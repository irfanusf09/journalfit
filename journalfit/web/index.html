JournalFit

Find the right journal, prepare the submission, fill in the forms.

One-time setup: journal list

The tool needs the free SCImago journal list (journal rankings and Scopus indexing).

  1. Open scimagojr.com/journalrank.php and click Download data.
  2. Drag the downloaded .csv file into the box below.
Drop the SCImago .csv file here or click to choose it

Optional: connect an AI

Without it the tool still finds and ranks journals. With it, it also checks scope like an editor, looks up missing metrics, reads author guidelines and writes your cover letter. Choose Claude, ChatGPT (OpenAI), Gemini or DeepSeek and paste its API key in Settings.
